## 🚀 Selected Engineering Projects

### 01. TRACE — Programming Lab & Code Assessment Platform

**Next.js · TypeScript · PostgreSQL · Redis · Docker**

A full-stack programming assessment platform where educators manage coding assignments and students write, execute, submit, and receive feedback on their solutions.

The central engineering challenge is **executing untrusted code while keeping the application, execution environment, and submission records properly separated.**

**Engineering highlights:**

- Developed persistent coding workflows with autosaved drafts, resumable sessions, and immutable submission attempts.
- Built visible/hidden test workflows, progress tracking, and rubric-based instructor reviews.
- Designed a queue-backed execution architecture with isolated Java/C++ runner components.
- Worked on separating code execution from application services, with attention to execution boundaries, resource constraints, and failure handling.

**What makes it interesting:** Code assessment involves more than compiling a program. It requires carefully managing execution isolation, submission integrity, asynchronous jobs, and the boundary between trusted application logic and user-submitted code.

## 🧠 How I Approach Engineering

I try to build with a few principles in mind:

- **Understand the problem before choosing the stack.** Requirements and constraints should drive architecture.
- **Prefer simplicity over unnecessary complexity.** A technology is useful only when it solves a real problem.
- **Think about failure, not just success.** State consistency, validation, security, and recovery matter as much as features.
- **Treat testing as part of development.** Passing a demo isn't the same as having confidence in the system.
- **Use AI as an accelerator, not a substitute for understanding.** I use AI-assisted development while actively reviewing architecture, debugging behavior, and verifying the code.

I'm still developing my engineering judgment, but that's exactly what motivates the projects I choose. Each one gives me a new class of problems to investigate and understand.
